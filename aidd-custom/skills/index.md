## Skills Index

- better-writer - Improve draft text for clarity, simplicity, and engagement using plain-language and persuasive techniques. Use when the user wants copy tightened, rewritten, or made easier to read without changing core meaning.
- brainstorm - Structured ideation: options with trade-offs, edge cases, scalability and DX, then a clear recommendation. Read codebase when relevant; do not edit code unless the user asks. Not a slash command; load as a skill when planning or comparing approaches.
- debug-analysis - Systematic debugging without editing the repo: search and read code, summarize findings, root cause, and fixes (described in text only). Use when investigating bugs or failures. Not a slash command.
- documentation - Plan and write technical documentation that is example-led, skimmable, and honest about gaps. Use for READMEs, guides, API docs, and internal runbooks.
- facades - Project facade functions for Prisma model modules: naming, single DB operation, raw returns, JSDoc, and explicit selects. Use when editing *-model.server.ts or *-model.server.js (or equivalent model facade files).
- name - Naming guidance for functions and variables. Use when choosing names for code, especially facades, factories, and booleans.
- react-guidance - React, React Router v7, ShadCN/ui, Tailwind v4, forms (react-hook-form + Zod), a11y, and i18n conventions for this codebase. Use when writing or reviewing .js, .jsx, or .tsx UI.
- svg-to-react - Convert SVG to optimized React TypeScript icon components. Use when converting SVG files or markup to React with IconProps.
- unit-tests - Vitest unit and integration test style and structure. Use when writing or reviewing tests.
- write - Draft or revise business-facing prose for clarity, warmth, and specificity. Use for blog posts, announcements, product copy, or any narrative where tone, structure, and banned-phrases guidance matter.
